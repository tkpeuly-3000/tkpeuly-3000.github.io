# Tabassum Peuly · Portfolio

Personal portfolio website, hosted on GitHub Pages.

## Files
* index.html  : page layout
* style.css   : colors and design
* script.js   : gear tracker, menu, animations
* data.js     : ALL YOUR CONTENT (edit this one to update the site)
* images/     : your photo and project images
* cad/        : CAD designs, one folder per design (see HOW-TO-ADD.md)
* apps/, projects/ : new apps and projects show up automatically (see HOW-TO-ADD.md)
* certificates/ : certificate PDFs or images (add the path in data.js)

## Updating
* Resume: not posted publicly; visitors request it on LinkedIn.
* New project: open data.js, copy one project block, change the words, upload a photo to images/ and put its path in image.
